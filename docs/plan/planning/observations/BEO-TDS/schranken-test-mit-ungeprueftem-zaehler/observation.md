# Ein Schranken-Test hängt an einem Zähler, den kein Test prüft

**Sub-Area:** `*` (Transport, Build und Gates)

Ein Nachweis „höchstens N Bytes gelesen“ prüft nur eine Obergrenze. Zählt die Testhilfe nichts, bleibt der Test grün. Eine Untergrenze (der Leser muss mindestens bis zu einer bekannten Stelle gelesen haben) prüft den Zähler mit.
