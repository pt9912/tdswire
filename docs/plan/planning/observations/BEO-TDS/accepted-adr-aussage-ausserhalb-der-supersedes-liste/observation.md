# Eine angenommene ADR sagt eine Aussage, die die Folge-ADR nicht in ihrer Supersedes-Liste führt

**Sub-Area:** `*` (ADRs)

[ADR-0028](../../../../adr/0028-referenzinstanz-fuer-tds-8-0.md) ersetzt wörtlich benannte Sätze von [ADR-0008](../../../../adr/0008-dotnet-kompatibilitaetstests.md), und die Aussage „der Server R bietet TDS 8.0 nicht an“ steht auch in [ADR-0007](../../../../adr/0007-fehler-und-attention.md) (Accepted), ebenso „gefolgert“ in Zeile 83 von [ADR-0008](../../../../adr/0008-dotnet-kompatibilitaetstests.md). Beide Stellen fehlen in der Liste; eine Accepted-ADR bleibt unverändert (`AGENTS.md` §3.5), die alte Lesart steht neben der neuen. Gesucht wird beim Schreiben der Folge-ADR: welche Accepted-ADRs sagen dieselbe Aussage, nicht nur die, aus der zitiert wird.
