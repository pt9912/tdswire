# Antworten eines echten SQL Servers sind nicht gemessen

**Sub-Area:** `*` (Entscheidungs-Slices der Welle `welle-entscheidungen-grundlage`)

Ein Entscheidungs-Slice stützt sich auf einen Spike-Testserver; was ein echter SQL Server sendet (Tokenreihenfolge, ordinale Zählung der RETURNVALUE, DONE-Statusbits, State und Meldung bei der Anmeldung), bleibt offen und gehört in den Referenzabgleich.
