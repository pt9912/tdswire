**Vorgang:** slice-fehler-mapping
**Fund:** Nummer, State, Text und Class der elf eigenen Codes sind Vorschlag, Setzung oder Festlegung; an einem echten SQL Server beobachtet ist allein 18456 mit State 1 und Class 14 (einmal, [ADR-0009](../../../../../adr/0009-authentifizierungsmodus.md) §Offen). Der echte Server sendet 208 mit Class 16 (R05), das Mapping mit Class 20, und er sendet bei Class 20 und 25 ein DONE mit `ERROR` und `SRVERR` samt weiteren ERROR-Token (R10), das Mapping nur ERROR und DONE mit `ERROR` ([ADR-0007](../../../../../adr/0007-fehler-und-attention.md)). Ob der Referenzclient die kürzere Folge annimmt, ist nicht am Produkt gemessen; `slice-qa-vergleichslauf-d` nennt die DONE-Statusbits allgemein, `SRVERR` bei Class 20 und 25 nennt kein Slice ausdrücklich.
