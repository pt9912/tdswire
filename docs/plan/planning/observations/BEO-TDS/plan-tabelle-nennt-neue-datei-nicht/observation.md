# Die Datei-Tabelle des Plans nennt eine beim Bau entstandene Datei nicht

**Sub-Area:** `*` (Planung)

Der Implementer erweitert die Datei-Tabelle in §3 vor dem Code und zerlegt dann beim Bau eine Klasse; die neue Datei fehlt in der Tabelle, und der Review bestätigt im Negativbefund „keine Datei darüber hinaus“, weil er die Tabelle gegen den Diff der Quelltexte nicht abgleicht. Die Verifikation fand die Abweichung (Plan gegen Code).
