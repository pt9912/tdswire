# Eine Folgepflicht aus der Verifikation steht als DoD-Zusage im Folge-Slice, ohne dass der Messweg zum Client geklärt ist

**Sub-Area:** `*` (Planung, Slice-Schnitt)

Die Verifikation eines Slice überträgt eine ungemessene Aussage („N ATTENTION ergeben N Bestätigungen“, ATTENTION im Leerlauf) als Folgepflicht in die DoD des Folge-Slice. Dessen Lauf löst sie über die Client-API nicht aus (der Client sendet nach Aktenlage nicht zwei ATTENTION, ein Leerlauf-ATTENTION kennt die API nicht); die Verifikation hält den Punkt offen, bis der Planner den Wortlaut auf das Belegte setzt und einen benannten Träger (Draht-Mitschnitt) bindet. Die Folgepflicht gehört mit ihrem Messweg in die Planung: Client-API oder Draht, und wer sie trägt.
