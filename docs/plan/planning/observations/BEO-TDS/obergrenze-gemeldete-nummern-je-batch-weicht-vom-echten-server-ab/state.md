**Stand:** gemessen, Entscheid offen — der Auflösungs-Trigger ist eingetreten: am 2026-11-07 meldet der echte SQL Server (2022 und 2025) jede unbekannte Nummer ohne Obergrenze (100, 101 und 150 auf dem Draht, bis 2000 am Client; M-22 im [Messprotokoll](../../../../../messungen/referenzabgleich.md#messreihe-zu-massenladen-merge-katalog-und-strukturänderung-messungen-vom-2026-11-07)); die Setzung von 100 widerspricht dem Messwert, die Angleichung von `SPEC-060` und Bau und der andere Träger des Schutzes nach [TDS-QA-02](../../../../../../spec/lastenheft.md#tds-qa-02--stabilität) sind dem Nutzer vorgelegt. Bisheriger Wortlaut: Auflösungs-Trigger: eine Messung am echten SQL Server (2022 und 2025) mit sehr vielen unbekannten Nummern in einem Batch (Zusatzmessung in Liefer-Punkt 3 von [slice-qa-vergleichslauf-d-messungen-bulk-merge](../../../in-progress/slice-qa-vergleichslauf-d-messungen-bulk-merge.md); EULA-Freigabe beim Nutzer). Bestätigt sie die Grenze nicht, wird die Setzung dem Messwert angeglichen, und der Schutz nach [TDS-QA-02](../../../../../../spec/lastenheft.md#tds-qa-02--stabilität) braucht einen anderen Träger (Entscheid des Nutzers). Die Setzung trägt `SPEC-060` mit demselben Trigger; Nutzer-Doku und Kompatibilitätsmatrix nennen die Grenze.
