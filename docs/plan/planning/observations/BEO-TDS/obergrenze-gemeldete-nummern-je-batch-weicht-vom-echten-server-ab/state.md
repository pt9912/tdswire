**Stand:** offen — Auflösungs-Trigger: eine Messung am echten SQL Server (2022 und 2025) mit sehr vielen unbekannten Nummern in einem Batch (Zusatzmessung in Liefer-Punkt 3 von [slice-qa-vergleichslauf-d-messungen-bulk-merge](../../../in-progress/slice-qa-vergleichslauf-d-messungen-bulk-merge.md); EULA-Freigabe beim Nutzer). Bestätigt sie die Grenze nicht, wird die Setzung dem Messwert angeglichen, und der Schutz nach [TDS-QA-02](../../../../../../spec/lastenheft.md#tds-qa-02--stabilität) braucht einen anderen Träger (Entscheid des Nutzers). Die Setzung trägt `SPEC-060` mit demselben Trigger; Nutzer-Doku und Kompatibilitätsmatrix nennen die Grenze.
