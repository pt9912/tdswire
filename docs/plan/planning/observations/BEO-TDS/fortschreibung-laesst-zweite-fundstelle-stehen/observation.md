# Eine Aussage wird an einer Stelle fortgeschrieben und an einer zweiten stehen gelassen

**Sub-Area:** `*` (Spezifikation, ADRs)

Eine Fix-Runde berichtigt die Fundstelle, die der Review nennt, und lässt dieselbe Aussage an weiteren Stellen stehen (hier: „`OutputParameter` bleibt bis zur Abbildung abgelehnt“ an drei Stellen der Spezifikation und in einer angenommenen ADR). Der Review nannte eine Stelle, die Verifikation fand die dritte; die ADR-Seite ist unveränderlich und braucht eine Folge-ADR. Gesucht wird die Kernaussage über `spec/` und `docs/plan/adr/`, nicht die genannte Zeile.
