# Aussagen in ADR und Vertragsdateien gehen über die Messung hinaus

**Sub-Area:** `*` (Entscheidungs-Slices der Welle `welle-entscheidungen-grundlage`)

Eine ADR oder Vertragsdatei, die aus einem Spike entsteht, formuliert Aussagen breiter als die Messtabelle im Slice belegt (zum Beispiel „dasselbe Ergebnis“ für ein weiteres Paket, ein Wert für beide Protokollpfade, ein Modus als nutzbar). Der Review findet sie als MEDIUM; behoben wird durch Nachmessen oder Einschränken.
